# Лабораторна робота №8 — варіант 10

## Запуск
Відкрийте `index.html` у браузері. Усі сторінки доступні з головної.

## Структура
- `gallery.html` — завдання 3, галерея за макетом для парних номерів.
- `cards.html` — завдання 4, картки за макетом для парних номерів; довгий текст перевіряє переповнення.
- `layout-columns.html` — завдання 5, mobile-first через колонки та рядки.
- `layout-areas.html` — завдання 5, mobile-first через `grid-template-areas`.
- `tree.html` — завдання 6, деревовидна структура з нумерацією через CSS generated content (`counter`).
- `control-questions.md` — відповіді на 15 контрольних запитань.
- `css/style.css` — спільні стилі, reset, CSS-змінні та медіазапити 768px/576px.

## Що потрібно зробити самостійно
1. Пройти CSS Grid Garden і додати скриншот результату до репозиторію.
2. Зареєструватися на CSSGrid.io, пройти уроки, додати скриншот прогресу та код уроків.
3. За потреби замінити фотографії на власні.
